## Step 3: Set Primary Domain

1. In GSC, go to the domain property (`ubgroup.info`)
2. Click "Settings" (gear icon)
3. Under "Primary domain", select "www.ubgroup.info"
4. This tells Google to use the www version in search results

## Step 4: Submit Sitemap

1. Go to "Sitemaps" in the left navigation
2. Click "Add a new sitemap"
3. Enter: `sitemap.xml`
4. Click "Submit"
5. The sitemap URL will be: `https://www.ubgroup.info/sitemap.xml`

## Step 5: Request Indexing

### For Important Pages:
1. Go to "URL Inspection" tool
2. Test these URLs one by one:
   - `https://www.ubgroup.info/`
   - `https://www.ubgroup.info/about`
   - `https://www.ubgroup.info/businesses`
   - `https://www.ubgroup.info/contact`
   - `https://www.ubgroup.info/leadership`

3. For each URL:
   - Enter the URL and press Enter
   - Click "Test live URL"
   - If successful, click "Request indexing"

## Step 6: Monitor Coverage

1. Go to "Pages" report (formerly "Coverage")
2. Check for any errors or warnings
3. Fix any issues that appear:
   - "Crawled - currently not indexed" - Usually resolves with time
   - "Page with redirect" - Should be fixed now
   - "Not found (404)" - Fix broken links

## Step 7: Set Up International Targeting

1. Go to "Settings" > "International targeting"
2. Under "Country", select "India" (since you're targeting Bilaspur, Chhattisgarh)

## Step 8: Monitor Performance

## Common Issues to Watch For

### "Crawled - currently not indexed"
- This is normal for new sites
- Usually resolves within 1-2 weeks
- Focus on creating quality content

### "Page with redirect"
- Should be fixed with our canonical URL updates
- Monitor in Coverage report

### "Submitted URL marked 'noindex'"
- Ensure no pages have `noindex` meta tags
- Check your robots.txt doesn't block important pages
